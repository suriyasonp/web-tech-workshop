# Environment Setup Guide

Install and verify:

- VS Code
- Git
- GitHub account
- .NET 10 SDK
- Node.js
- npm
- Docker (optional for workshop support)

## Verification

```bash
git --version
dotnet --version
node --version
npm --version
docker --version
```

## Workshop Readiness

- Can clone repository
- Can run `dotnet new web`
- Can run `npm create vite@latest`
- Can commit and push to GitHub
- Browser can open local backend and frontend ports
