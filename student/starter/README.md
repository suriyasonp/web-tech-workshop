- Lab 02 creates `backend/TaskApi` here.
- Lab 08 adds the backend test project and solution file.
- Lab 09 creates `frontend/` here.
- Labs 10–14 continue from those projects.

Keep your work in this directory. For recovery, compare with the matching files under `../../instructor/solutions/` without replacing unrelated work.
