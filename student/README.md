# Student Guide

Use the repository's `main` branch throughout the workshop. Start with [Lab 00](labs/lab-00-environment.md), then complete Labs 01–14 in order.

## Working Area

Build your cumulative application under `student/starter/`:

- create the backend under `student/starter/backend/` in Lab 02;
- create the frontend under `student/starter/frontend/` in Lab 09;
- keep using those folders in later labs.

The repository does not contain a pre-built student application. Each lab builds on the previous one. If you get blocked, compare only the relevant part with `instructor/solutions/`, then continue in your own working area.
