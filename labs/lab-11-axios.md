# Lab 11 — API Integration with Axios

## Objective
Connect Vue to the backend.

## Steps
1. Add Axios.
2. Create one Axios instance.
3. Read API base URL from `.env`.
4. Create `taskService`.
5. Load tasks into the Tasks view.
6. Handle loading and error states.

## Checkpoint
Tasks displayed in Vue come from the backend.

## Challenge
Add a response error interceptor.

## Expected Result
Frontend and backend communicate through a service layer.
