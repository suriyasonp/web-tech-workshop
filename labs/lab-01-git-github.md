# Lab 01 — Git & GitHub

## Objective
Practice clone, branch, commit, and push.

## Steps
1. Clone this repository.
2. Create a personal workshop branch.
3. Add a small Markdown note.
4. Commit using a clear message.
5. Push the branch.

## Checkpoint
Your branch exists remotely.

## Challenge
Inspect `git log --oneline` and explain HEAD.

## Expected Result
Participants can recover their work using Git.
