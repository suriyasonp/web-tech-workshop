# Lab 05 — EF Core + SQLite

## Objective
Replace in-memory data with persistent storage.

## Steps
1. Add Entity Framework Core packages.
2. Create `TaskEntity`.
3. Create `AppDbContext`.
4. Configure SQLite.
5. Create and apply a migration.
6. Connect CRUD endpoints to the database.

## Checkpoint
Tasks persist after application restart.

## Challenge
Seed sample tasks.

## Expected Result
A persistent backend.
