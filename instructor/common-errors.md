# Common Errors

## .NET
- Wrong SDK version
- Port conflict
- HTTPS development certificate issue
- Migration not applied
- Wrong connection string

## Frontend
- Wrong Node version
- `npm install` not run
- Wrong API base URL
- CORS failure
- Token missing from Authorization header

## Git
- Working on wrong branch
- Uncommitted changes block checkout
- Merge conflict
- Remote branch not pushed

Prefer restoring a checkpoint over prolonged debugging during delivery.
